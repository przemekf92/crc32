Usage: crc32.py [OPTION...] <FILE...>
Print CRC32 checksums.
When FILE is -, read standard input.
Options:
      --lhex        lowercase hexadecimal format (default)
      --uhex        uppercase hexadecimal format
      --uint        unsigned int decimal format
      --sint        signed int decimal format
      --md5         use MD5 instead of CRC32
      --sha1        use SHA1 instead of CRC32
      --sha256      use SHA256 instead of CRC32
      --help        display this help and exit
